# Knowledge Management using Obsidian as Knowledge Base (KB)

## Instructions
1. Identify if the use is to create/update or retrieval knowledge.
2. The CLI is already installed.

### Retrieval

1. **Get where the Obsidian vault is** - Run `obsidian vault` to locate the path
2. **Browse the directory structure in the path** - Run `tree -d <vault path>`
3. **Read relevant notes** - They are organised under relevant topic folders

### Write

Run `obsidian vault` to locate the path first. Then create/update the files directly.

### Help

```sh
# Run the help command
obsidian help
```
